# Swag Labs — test automation

Generated by Applause AI on the [applause-ai-taf](https://github.com/ApplauseAuto/applause-ai-taf) framework.
Web tests run on **Playwright**.

## Setup

```bash
npm install
npx playwright install --with-deps
cp .env.<profile>.example .env.<profile>   # fill in values
```

Environment profiles and targets live in `customer.config.ts`; pick one with `TEST_ENV=<profile>`.
`auth.mode` is `'none'`: every test performs its own login. Switch to `'per-worker-storage'` and
implement `src/setup/login-flows/login-flow.ts` to log in once per worker instead.

## Run

- Web: `npm test` (Playwright, all enabled browsers) · `npx playwright test --grep @<suite>`
- Web on BrowserStack: `npm run test:bs` (set `BROWSERSTACK_USERNAME` / `BROWSERSTACK_ACCESS_KEY`)

## Layout

- `src/pages/<app>/*.page.ts` — generated page objects (shared across tests); `src/pages/components/` — shared components
- `src/tests/<app>/*.spec.ts` — generated tests
- `src/fixtures/`, `src/config/`, `src/visual-locator/` — framework
